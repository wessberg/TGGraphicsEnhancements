Version 1.2.3 for both game versions contains this native DLL. Defender quarantines it during a file read, preventing frame generation from loading.

On October 9, 2026, Defender detected the installed file at 15:44 and again at 17:18 local time after reinstallation. Reading the original build output with Python also triggered the detection at 17:24, without running the DLL or the game.

We have a saved October 7 build, SHA256 55843c485e3796ace2e7819fef78b7685bbcaaaeae4d7695ace106e021b996cb, which scans clean under the same Defender definitions. Every other byte, including executable code, imports and data, is identical. The timestamps change from 2026-10-07 19:23:43 UTC to 2026-10-09 11:34:01 UTC. Neither file was patched for this comparison.

MpCmdRun custom scans with DisableRemediation reproduce the released DLL detection and accept the October 7 binary, the previous public 1.2.0 DLL, and the accompanying Graphics Bridge, Better Upscaling and Neural Rendering DLLs.
