TG Frame Generation 0.5.0: DLSS, FSR and XeSS frame generation with Reflex, XeLL or Anti-Lag 2

Requires BepInEx for your game version:
  Mono (modding) branch:  BepInEx 5
  Standard (IL2CPP):      BepInEx 6 IL2CPP (untested)
Install only ONE runtime package per game installation.

Close the game and merge this package's BepInEx folder into the game folder. Nothing else is
needed: no launcher, no replaced graphics DLL, no Steam launch options, no steam_appid.txt.
Start the game from Steam as usual. TGFG-Package-manifest.json can go in the game folder for
Test-Setup.ps1; the game doesn't need it.

Options > Video gains two rows below the upscaler:
  Frame Generation  Off, or DLSS, FSR or XeSS as supported by your GPU. It uses the game's
                    own motion vectors and depth: from DLSS upscaling when that's on, and
                    straight from the game's renderer with TAA, STP or no anti-aliasing, so
                    it works on AMD and Intel GPUs too.
  Low Latency       NVIDIA Reflex, Intel XeLL or AMD Anti-Lag 2, as supported. It stays on
                    while frame generation is on: DLSS needs Reflex and XeSS uses XeLL.
FoA Mod Manager shows the same rows. The settings are saved in
  BepInEx/config/com.wessberg.tgframegeneration.cfg
Settings from older TGFG versions are carried over on first start.

F8 turns frame generation off. If something looks wrong, check these logs:
  BepInEx/TGFrameGeneration/Autoload.log
  BepInEx/TGFrameGeneration/Native/TGFG.Native.log
For a diagnostic report, set "Write diagnostic report now" to true in the [Advanced] section
of the config file. Reports go to BepInEx/TGFrameGeneration/diagnostics; read one before sharing it.

To stop TGFG from loading its graphics backend, close the game and create an empty
  BepInEx/TGFrameGeneration/disable-autoload.txt
Setting Frame Generation to Off is not the same: the backend keeps running.

Updating by hand from 0.4.x or 0.3.x: copy the whole BepInEx folder of this package, including
Native/FidelityFX and Native/XeSS. Delete BepInEx/TGFrameGeneration/Native/Streamline/sl.interposer.dll
if it's there: TGFG now uses NVIDIA's interposer under the name TGFG.Streamline.dll, so the RenoDX
DLSS addon ("DLSS 5") doesn't hook it.

To uninstall, close the game and remove these TGFG files:
  BepInEx/patchers/TGFG.Autoload.dll
  BepInEx/plugins/TGFrameGeneration/
  BepInEx/TGFrameGeneration/Native/
The config file and logs can stay. Don't remove BepInEx itself or other mods.

The NVIDIA, AMD and Intel runtimes in Native/ are redistributed under their own licenses, which
are next to them: Native/Streamline/LICENSE-*.txt, Native/FidelityFX/LICENSE-FidelityFX.md and
Native/XeSS/LICENSE-XeSS.txt.

Tested on an RTX 5080: DLSS frame generation (fixed and dynamic, with and without ReShade + RenoDX
HDR and the RenoDX DLSS addon), FSR frame generation and XeSS frame generation with XeLL, with and
without DLSS upscaling. Anti-Lag 2 (AMD GPUs) and XeLL on its own (Intel GPUs) have not yet been
confirmed in game. The game must render with Direct3D 11, its default.
